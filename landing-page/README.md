# 418 Property Services — Landing Page

A responsive landing page for **418 Property Services**, a junk hauling business
branching into property cleanouts and moving/labor help. Built from scratch with
plain HTML, CSS, and JavaScript (no frameworks) as a learning project.

## Features

- Fully responsive layout (looks intentional on phone and desktop)
- Mobile hamburger navigation menu
- Services section
- "Request a Free Quote" form with JavaScript validation

## Built with

- HTML5 (semantic, accessible markup)
- CSS3 (Flexbox, Grid, media queries, custom properties)
- Vanilla JavaScript (no libraries)

# 418 Property Services — Bid Calculator

A fast, mobile-friendly web app that helps 418 Property Services price jobs (junk
hauling, property cleanouts, moving/labor help) consistently and on the spot. Built
from scratch with plain HTML, CSS, and JavaScript (no frameworks) as a learning project.

## What it does

Enter a few job details and instantly get a suggested bid price.

## Built with

- HTML5 (semantic, accessible form markup)
- CSS3 (mobile-first, Flexbox, Grid, media queries, custom properties)
- Vanilla JavaScript (no libraries) — the pricing logic
